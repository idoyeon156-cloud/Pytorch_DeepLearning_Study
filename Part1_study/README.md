# Chaper 1

## 지도학습, 비지도학습, 강화학습
- 지도학습: 학습에 사용하는 데이터셋에 정답을 같이 제공
- 비지도학습: 데이터셋에 정답을 제공하지 않음
                → 이상치 탐색, 군집화 (clustering)
- 강화학습: 데이터를 활용하지 않음. 인공지능이 특정 환경과 상호작용을 하면서 학습이 진행됨. 목적에 부합하는 행동을 하면 보상을, 반대되는 행동을 하면 패널티를 줌. 인공기능은 보상을 최대화하는 행동을 하도록 학습.
  
## 문제 해결 과정
문제 정의 → 데이터 수집, 가공 → 모델 설계 → 모델 학습 → 성능 평가
    
### 인공지능 모델 설계
- ML: scikt-learn, xgboost
- 딥러닝: 파이토치, 텐서플로우
